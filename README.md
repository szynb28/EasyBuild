# EasyBuild

EasyBuild 是一个面向 Minecraft 建筑玩家的 Paper 插件，提供基于 FastAsyncWorldEdit（FAWE）的快捷复制、粘贴、填充、曲线与模板随机粘贴工具。

[English manual](README.en.md)

## 环境要求

| 项目 | 要求 |
| --- | --- |
| 服务端 | Paper 1.21.4 |
| Java | Java 21 |
| 前置插件 | FastAsyncWorldEdit（FAWE） |
| 构建工具 | Maven 3.9+（仅自行构建时需要） |

> EasyBuild 的 `plugin.yml` 将 FAWE 声明为硬依赖。请先安装并成功启动 FAWE，再安装 EasyBuild。

## 安装

### 直接使用构建产物

1. 使用下方“从源码构建”生成 `target/EasyBuild-1.0.jar`。
2. 将该 JAR 放入 Paper 服务端的 `plugins/` 目录。
3. 确认 `plugins/` 中已有与服务器版本匹配的 FastAsyncWorldEdit。
4. 重启服务端；在游戏内执行 `/kjjzgj`（或 `/kj`）打开工具菜单。

### 从源码构建

```powershell
mvn clean package
```

构建成功后，插件文件位于 `target/EasyBuild-1.0.jar`。项目依赖 Paper API 与 FAWE 的 Maven 仓库，首次构建需要联网下载依赖。

## 快速开始

1. 给予建筑玩家使用 WorldEdit/FAWE 所需的权限。
2. 在游戏内用木斧完成 WorldEdit 选区。
3. 执行 `/kj`，从菜单领取需要的工具。
4. 将工具放在主手，根据下列说明操作。

许多功能直接调用 FAWE 的 `//copy`、`//paste`、`//set` 和 `//undo`；因此是否可用、可编辑范围与上限取决于玩家已有的 FAWE 权限配置。

## 命令

| 命令 | 别名 | 用途 |
| --- | --- | --- |
| `/kjjzgj` | `/kj` | 打开快捷建筑工具菜单 |
| `/bc` | — | 使用当前 WorldEdit 选区作为模板，沿已记录的曲线点生成曲线 |
| `/bcpos set <名称>` | — | 记录准星所指方块为一个曲线点；参数仅作占位 |
| `/bcpos undo` | — | 删除最后记录的曲线点 |
| `/bcpos clearall` | — | 清空全部曲线点 |

## 工具说明

### 铁锹：快捷复制与粘贴

- 右键：执行 `//copy -e`。
- 左键：按当前粘贴设置执行粘贴。
- 潜行右键：执行 `//rotate 90`。
- 潜行左键：执行 `//flip`。
- 按 `F`（交换主副手）：执行 `//undo`。
- 丢弃键 `Q`：打开粘贴设置菜单。

粘贴设置菜单可切换：以所点方块为参考位置、忽略空气（`-a`）、粘贴实体（`-e`）、粘贴后选中（`-s`）。

### 钻石锹：快捷填充

- 右键：开关快捷填充模式。
- 开启后，放置任意方块会改为对当前 WorldEdit 选区执行 `//set <手持方块>`。
- 按 `F`：执行 `//undo`。

### 骨粉：快捷种树

- 左键：打开树种选择菜单。
- 右键方块：在该方块上方生成已选树种。

树木生成不通过 FAWE 历史记录处理，通常不能用 `//undo` 撤销。

### 金锹：曲线生成

- 右键方块：依次记录曲线经过的点（至少两个）。
- 左键：以当前 WorldEdit 选区中的非空气方块为横截面模板，沿记录点生成曲线。
- 按 `F`：执行 `//undo`；潜行按 `F`：删除最后一个曲线点。
- 按 `Q`：清空全部曲线点。

先用 WorldEdit 木斧制作一个包含建筑横截面或片段的选区，再记录路径点并左键生成。复杂或大面积选区会产生大量方块修改，建议先在测试区域验证。

### 箭：三点曲线参数工具

- 非潜行右键方块：依次设置 P1、P3、P2；设置完成后再次右键会清空这些点。
- 左键：在 `n = 2` 与 `n = 3` 间切换。
- 潜行右键：设置控制点 `nb`；潜行左键：设置控制点 `nf`。

该工具目前用于记录曲线参数；它不会直接放置方块。

### 木棍：模板与随机粘贴

- 右键：执行 `//copy`。
- 潜行右键：将当前剪贴板保存为当前标签下的模板；随后在聊天栏输入模板名称。
- 左键：从当前标签随机挑选模板，以忽略空气方式粘贴。
- 潜行左键：随机粘贴，但不忽略空气。
- 按 `F`：执行 `//undo`。
- 按 `Q`：打开标签与模板管理菜单，可创建标签、切换标签并保存当前选区。

模板将保存到插件的数据目录中，按标签分目录管理。请定期备份服务端的 `plugins/Leaf/`（实际目录由插件名称决定）以保留自定义模板。

## 常见问题

**插件未加载或提示缺少依赖**：检查服务端版本是否为 Paper 1.21.4，并确认 FAWE 已安装且成功启用。

**工具无效果**：确认工具是通过 `/kj` 菜单领取的专用物品，并检查玩家是否有相应 WorldEdit/FAWE 权限。

**粘贴或保存模板失败**：先用 WorldEdit 创建选区并执行复制；检查控制台中的 FAWE 报错和服务器的编辑限额。

**曲线生成失败**：需要至少两个曲线点，以及一个包含非空气方块的 WorldEdit 选区。

## 开发

```powershell

```
